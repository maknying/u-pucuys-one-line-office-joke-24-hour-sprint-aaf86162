One original one-line joke about office life, written for the
[make.fun bounty "One-Line Office Joke: 24-Hour Sprint"](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162).
`main.py` writes exactly that line to `entry.txt`.

> I asked for a raise and got a pizza party, so now I'm the best-fed underpaid employee in the building.

## Run it

```sh
python3 main.py
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is not set).
